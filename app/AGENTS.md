# SthStart 前端开发强约束规则 (Frontend Core Rules)

本规则适用于 `app/` 目录下的所有页面、组件与样式代码。所有前端修改必须无条件遵守以下准则：

## 1. 多列工作台高度与滚动完全隔离
- 工作台根容器必须使用 `h-screen max-h-screen overflow-hidden`（或 `h-[100dvh]`），禁止使用 `min-h-screen`。
- 多列主体容器必须包含 `min-h-0`。
- 左侧栏、中间画布、右侧伴侣栏三部分必须各自具备 `h-full overflow-y-auto` 独立滚动上下文。
- **严禁中间内容增加时拉伸左右两栏的高度**。中间无论内容多长，左右两栏始终保持视口高度，底部固定操作（如建议卡片）不得偏移。

## 2. 文本断行与排版规范
- 中文对话气泡与段落卡片单行宽度必须保证 **25 ~ 45 个汉字**（约 500px ~ 800px），严禁因容器过窄出现 5 ~ 6 字的畸形断行。
- 承载文字或自适应卡片的 `flex-1` 容器必须同时添加 `min-w-0`。

## 3. 功能入口唯一性与去重
- 同一视口内严禁提供多个相同功能的按钮（如聊天区内 AI 按钮与右侧 Copilot 重复）。
- 标题展示禁止机械拼接导致冗余（如 `第 1 幕 阶段一`）。

## 4. 设计系统 Token 强制使用
- 必须使用语义化 Token：`bg-paper`、`bg-surface`、`text-ink`、`text-muted`、`bg-accent`、`var(--radius-panel)`。
- 禁止硬编码原生颜色值（如 `#ffffff`、`#333333`）。

## 5. 强制浏览器截图验收
- 任何 UI 布局变动完成后，必须运行 `node scripts/take_screenshot.mjs`，并通过 `view_file` 检查真实浏览器渲染截图，确认三栏高度隔离与排版无误后方可交付。
