## 3. 编写顺序与验收

### 第一步：重新建立当前基线

先运行已有健康检查和提案文件。记录结果是 passed、failed 还是 fixture error；不能把前端重构直接认定为 API 失败原因。现有 Python fixture 只有 Service，没有 Portal、浏览器和 MCP fixture，这些仍是待编写内容。

```powershell
.	ests\python\.venv\Scripts\python.exe -m pytest tests/python/test_health.py tests/python/story/test_story_proposals.py -v
```

### 第二步：B0 项目入口

准备独立 fiction 项目和章节；访问 `/apps/projects/{id}`；核对本次标题，点击 role=link 的“继续写作”；确认最终进入同 ID 的 `/apps/story/{id}`。再选择本次章节并检查 A 正文。项目标题存在不能单独证明章节数据正确。

第一次用桌面 1440×900。页面定位先通过 role、name、可见容器限定；不要复制 TS 参考中的 `.first()` 来消除多匹配。遇到多个匹配先解释它们分别来自侧栏、抽屉还是其他卡片。

### 第三步：B1/B2 保存

B1 把 A 改为 B，等待本次 PUT 成功，用管理员 API 读回 B，再刷新确认 B。B2 独立创建数据，拦截本次章节 PUT 为 503，确认本机 B、正式 A；刷新后按恢复提示恢复 B。通过源码视图按钮的 aria-pressed 与编辑框可见性确认当前能编辑，不能在预览状态直接等待 textbox。

### 第四步：C/D 协议与串联

C 保持主指南的真实 MCP 读取/提案和撤销用例。D 从新总览开始，保存 B 后再用 MCP 读版本，提交 C。打开“更多项目操作”→“审阅提案”，根据建议标题限定本次提案卡片。处理原生 confirm 后，分别检查 decision、accepted、正式正文 C 与 revision+1，以及刷新后页面 C。

### 第五步：最小移动端检查

在 390×844 下从项目总览进入编辑器，打开项目资料抽屉选择章节，验证能看到源码输入与正文。按钮名称应按当前工作区和实际页面核对，不猜“汉堡菜单”图标名。首轮不复制整套 D 到多个视口。

### 第六步：E 单场景 Skill 观察

模型宿主若加载创作套件，就比较“套件/无套件”，在报告中说明观察的是其中连贯性任务。若评估器加载单独源模块，则记录模块实验。两者不是同一实验条件，不能合并分数；不自动运行真实模型。

## 4. 新模块的后续代表用例

这些是本路径完成后的候选，每次选一个，不作为本轮学习门槛。

| 模块 | 一个代表行为 | 需要防止的错误理解 |
| --- | --- | --- |
| 参考资料 | 加入引用后正式设定不变；明确采用后创建设定，重复采用不重复新增 | 引用不等于正式采用 |
| 角色 | 采用已发布角色版本，库中更新后项目来源提示可见 | 项目角色不会被同名库角色自动覆盖 |
| 制作 | 用已保存章节修订创建制作版本，后续改正文不改变冻结来源 | 制作版本不是导出成品 |
| 媒体 | 加入项目建立引用，解除引用不删除原媒体 | 引用不会扩大底层读取权限 |

依据：[产品职责](../PRODUCT_WORKSPACE.md)、[项目总览](../../app/features/projects/project-workspace.tsx)、[当前浏览器参考](../../tests/e2e/learning-story.spec.ts)、[独立学习配置](../../tests/config/playwright.learning.config.ts)。

## 5. 运行入口与报告

`npm run test:e2e:learning` 会构建并运行 TS 学习参考流程；它不会执行 Python。根 Playwright 配置忽略 learning-story.spec.ts，故普通 test:e2e 通过不能代替该流程通过。独立 learning 配置使用临时数据库、媒体、日志，默认 Service 4800、Portal 4873；可由 E2E_SERVICE_PORT/E2E_PORTAL_PORT 覆盖。Python fixture 的动态端口以本次返回值为准。

当前 TS 参考还尝试 DELETE 项目，但 Story 管理员路由没有项目删除接口。不要复制这个清理步骤；使用临时环境整体清理。服务启动、断言失败和 teardown 错误分别报告。启动进程与浏览器的资源关闭仍按主指南第 4 章处理。
