已有接口：

- `flush(save, onError)`：调用传入的异步保存函数，返回 `Promise<boolean>`。
- `save(document, version)`：成功时返回新的版本号；失败时拒绝 Promise。

3. 验证保存失败的返回值，以及正文、版本、待保存状态和阻塞状态。
4. 再调用一次 `flush`，验证在未解除阻塞时没有再次发出保存请求。

完成后继续恢复场景：显式解除阻塞，用成功的保存函数重试；验证收到的正文与版本、新版本、待保存状态和错误回调次数。
