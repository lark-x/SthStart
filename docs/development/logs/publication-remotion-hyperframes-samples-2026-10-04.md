# 雪山回声：两个真实视频引擎的小样

## 已交付

- Remotion 4.0.532：`artifacts/publication-motion-comparison-20261004/remotion.mp4`，32,851,066 字节。
- Hyperframes 0.8.120 + GSAP 3.15.0：同目录 `hyperframes.mp4`，26,101,335 字节。
- 两者都是 1080×1920、30 fps、2038 视频帧，约 67.93 秒，H.264 + AAC。
- 对比页 `http://127.0.0.1:3092`，可同步播放、选择试听的一版、暂停、从头播放、下载，并展开上一版作为对照。
- Remotion Studio：`http://localhost:3090/SnowEcho`；Hyperframes Studio：`http://localhost:3091/#project/hyperframes`。
- 可重现源码：`experiments/publication-motion-comparison/`，各子项目独立安装依赖；没有加入正式导出服务。

## 对比如何控制变量

复用原验收活动 `5df698a8-d7ab-4c91-8f4d-9c47c27c4c88` 的六张图片和六段实际配音。
相同素材裁切、时间线、字幕内容、字体与声音，两个引擎分别实现同一套演出稿。
不是让一个引擎套好看的模板、另一个只拼接幻灯片，因此两版视觉接近是预期结果。

新演出包括标题开篇、墨色漫画底、错位纸色画格、人物色字幕卡、句级出现、小幅推近与横移、短入场、雪粒、蓝光提示和结尾。
原始图片不改写；裁切副本明确保存在实验产物中。合成的低音量风声和晶体提示音没有第三方音乐版权素材，也没有新增 TTS 或模型调用。

## 实际检查

`verification.json` 的 13 项检查全部通过：两版尺寸、帧率、时长、全长音轨；对比页实际同时播放、只放出一个声音；桌面与 390px 窄屏无横向溢出；页面无运行时异常。
实际查看了两版在 5、17、28、38、48、58 秒的解码帧和桌面/窄屏截图。
Remotion 独立 TypeScript 检查通过。Hyperframes lint 无错误、9 条结构警告，已在实验 README 中披露；未放宽 lint 规则。
Hyperframes 由真实 CLI 捕获和编码成片，不是录屏；Remotion 同样由真实 CLI 渲染。
没有改数据库、重新生图、重新配音、部署主应用、提交 Git 或上传平台。

## 不能宣称已解决的质量问题

- 第四张原图主体只有约 230×210 像素，放大后的试管仍模糊，不是换渲染器就能变清晰。
- 第六张人物仍趴在桌面，不能声称表现了写字动作。
- 六句现有配音没有角色分声线或情绪表演；字幕按句长估计时段，不是逐字语音对齐。
- 六个镜头仍主要使用同一画格模板；没有人物分层、口型、动作动画或复杂多格调度。
- 冒烟播放和音轨探测不代表已经完成人工逐句发音、情绪和专业混音验收。
- 此次不是性能基准；文件大小不能作为框架画质优劣的结论。

这是验证两个引擎都能实现同一演出方案的原型。正式接入前需由用户看成片确认视觉方向，再细化多格版式、镜头节奏、配音和字幕对齐。

## 重启预览

对比页：在项目根目录执行 `node experiments/publication-motion-comparison/serve.mjs`。
Remotion：进入其子目录执行 `npx remotion studio --no-open --port=3090`。
Hyperframes：进入其子目录执行 `npx hyperframes preview . --port=3091 --background`；停止用相同路径的 `--stop`。
其余重现步骤和当前 lint 警告见实验 README。
