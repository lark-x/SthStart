# 剧情发布链路：真实 ComfyUI 验收（2026-10-04）

## 结论

**真实生图、在线配音及真实配音视频的隔离功能链路通过；画面质量未通过；DSH 实际创作模型自主完成方案仍未验证。不能据此宣称正式成片已经验收通过。**

## 已验证的功能

1. 新测试项目、章节及真实不可变修订 → Story“制作作品”入口。
2. 标准 stdio MCP 客户端实际加载八个制作工具，分段读取来源、提交方案、读取状态；未批准时不能运行。**这是协议联调，不是 DSH 内实际创作模型自行完成分镜的证明。**
3. 浏览器保存绘制尺寸、刷新恢复、人工确认配置与预算。
4. 经统一执行器串行发出六次真实 ComfyUI `/prompt`；所有任务有可读图片产物，选入独立制作文档并可导出。
5. 六条生成任务分别与 ComfyUI `/history/{promptId}` 核对：工作流图 = 保存的任务快照 = AI 调用请求快照；正负提示词、seed、模型与尺寸全部一致。
6. 发布 ZIP 包含六张 PNG、封面、文案及 manifest；不包含视频、字幕或配音。已检查 ZIP 文件名，不含凭据文件；本轮没有配置真实语音密钥。
7. 浏览器自动化在 1440×900、390×844、1920×1080 完成，JS 错误与 HTTP 错误均为空；已人工查看桌面画面、导出及窄屏截图。没有根视口横向溢出。
8. 测试库 `PRAGMA integrity_check = ok`，`foreign_key_check` 无记录；本轮脚本改动后类型检查通过。

原先模拟链路的17个靶向测试、契约37/37、Portal18/18及构建结果见上一份实施报告，本轮没有把这些模拟结果算作真实配音验证，也没有重复运行无关全站测试。

### 配置调研记录（实际配音前）

用户指定 `stepaudio-3-tts` / `stepaudio-2.5-tts`。官方 TTS 文档确认两个模型均支持 `POST /v1/audio/speech`，当前代码发送 model、input、voice、speed 与 MP3 返回格式，基础接口可对接。

实际测试前尚需确认提供商根地址、声音 ID、服务端密钥位置；现已从用户的配置核对完成，见上节。模型名称本身不能证明已配置。官方普通 API 根地址为 `https://api.stepfun.com/v1`，Step Plan 使用 `https://api.stepfun.com/step_plan/v1`，转发平台应填写其自身地址和对应密钥。不要把密钥明文发到对话或写进报告。

官方文档：<https://platform.stepfun.com/docs/zh/api-reference/audio/create-audio>。单次最多1000字符；2.5/3的括号内容可被作为不发音指令；不支持 `voice_label`，可用 `instruction`。当前项目尚未提供专用情绪指令、音色克隆或词级时间戳配置，不能声称全部高级能力已经接入。
