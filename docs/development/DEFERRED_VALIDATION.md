## 稳定化阶段的执行顺序

1. 先完成测试端口隔离和 H3 严格就绪检查。
2. 再执行 Worker 协议、异常上传和真实视频 Artifact 验证。
3. 然后进行 Windows H3 三种模式实机验证和长任务 SSE 验证。
4. 最后执行全平台 CI、浏览器回归、性能和隐私验收。

每项完成后，应在阶段日志记录环境、版本、结果和已知限制；不能只删除本页条目。
