# 共用界面统一：主题、选中态与工具栏

这一轮沿用优化版 B 的页面结构。暖夜底色和强调色保留；暖白使用灰紫，云白使用偏冷的靛蓝，深空使用低饱和蓝紫。四套皮肤共用一套选择规则。首页入口以同样的表面和图标呈现，颜色留给主动作、当前选择和有实际含义的状态。

| 场景 | 规则 |
| --- | --- |
| 全站导航 | 当前模块使用轻底和短标记；不以浮起的重阴影表达当前页。 |
| 页签 | 共用 `PageTabs`，选中用短底线和强调文字；局部页签附轻底。指针悬停不会覆盖选中态，键盘焦点另有轮廓。 |
| 当前行、筛选项和分页 | 对有真实选中状态的控件使用 `ui-choice` 或已有共用分页规则。用低饱和底色和细轮廓，取代粗侧边条、实色大块和多重描边。收藏与任务状态保留自己的含义。 |
| 表单 | 常规输入和选择复用现有控件；各皮肤的输入光标、复选框、单选框与文字选取都沿用当前主题。 |
| 空状态 | 在现有面板内显示说明和下一步，避免再套一张带阴影的卡片。区分尚无数据和筛选无结果。 |

资料库、剧情大纲、镜头与制作视图、原作目录、日历、生成模式和工作流列表应用了共用选择样式。角色库视图切换复用共用页签，新建、导入和更多操作合并进页头。公共服务设置保留一个全局手动刷新入口，表单保存后的自动刷新照常执行。邻舍应用内部不在本轮范围内。
