# 角色库批量导入与共用筛选

日期：2026-09-10。适用范围：SthStart 公共角色库与活动新增页面；不修改邻舍。

## 已实现

- 角色库与活动选人共用 CharacterFilters、CharacterPagination、useCharacterBrowser。
- 姓名、英文名、别名、作品及标签搜索；作品、标签、分组多选；收藏；更多筛选支持作品类型、原创/IP、外观参考图、外观描述、演绎、来源及待整理状态。
- 同类多选默认 OR，不同条件 AND；标签可切换全部匹配。标签候选按选中作品收窄。
- 新 browse 接口由 SQLite 执行筛选与分页，默认每页 24、最大 100；总数来自完整结果，不受原列表的 500 条截断影响。排序增加 id 作为稳定次序。
- 作品目录支持标准名、别名、类型；预置原神及星铁常用别名。既有人设 work 文本兼容查询，不批量改写历史版本。
- 收藏、跨页选择、批量整理作品/标签/分组/演绎/创作类型。默认作品与演绎仅补空白，标签和分组追加；可以明确选择替换全部标签或分组。
- 活动选人跨页多选，显示已选名单，隐藏已加入角色；按活动容量限制选择。先读取全部角色快照，再统一加入，读取失败时不产生半份名单。
- 本地 PNG/JSON 多选及拖放批量导入，每批最多 500 张；逐张解析和提交，独立错误及重试。
- 批量预览保留原卡标签，支持统一补充资料、单项编辑、封面作为头像/参考图。普通图片明确提示不是角色卡。
- 重复提示区分相同内容、同来源和同名；默认不选择相同内容，允许明确另存或选择更新对象。更新沿用草稿版本冲突检查。
- 导入预览、字段映射、原卡来源快照及现有提交幂等机制继续复用。更新已有角色保留收藏、合并分组与标签，不用空演绎清除已有值。
- 浏览器保存批次条目和会话 ID，未提交会话按原有 24 小时有效期恢复；成功项不会重复提交。解析失败文件刷新后需重新选择，不在浏览器持久保存文件内容。

## 数据与接口

迁移 18 `character-library-organization`：新增 `character_profiles.organization_json`、`character_works` 及列表查询索引。服务启动按现有迁移机制升级，无需重置数据库。

新增接口（门户沿用现有 admin 代理）：

- `GET /api/v1/admin/characters/browse?filter=<JSON>`
- `PUT /api/v1/admin/characters/organization`
- `PUT /api/v1/admin/characters/works`
- `GET /api/v1/admin/characters/import-sessions/:id/duplicates`

导入 candidate 增加可选 tags 与 organization，保持旧会话和旧调用方兼容。作品规范化在预览阶段执行，保证预览值和字段来源哈希一致。

旧角色列表接口继续供未改造的角色关系/笔记关联控件使用；本次两个页面已经切换到新的完整分页查询。新增在线搜索多选下载不在这一版范围，既有在线单张预览/导入继续可用。
