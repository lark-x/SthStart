# 优化版 B：全站布局统一与验收

## 依据与边界

用户最新提供的《个人创作空间_资料库_优化版原型_.html》是本轮布局依据，取代先前误读 B 的密度整改方案。原型实图：`artifacts/layout-unification-20261109/reference-1440.png`。

本轮采用图标导航、单一模块顶栏、独立工作面、紧凑元信息与按需属性面板。保留暖夜等现有四种皮肤；不引入绿色主色。原型演示切换条、优化批注、虚构关联项目/引用数、未实现的引用块功能不进入产品。桌面优先，移动端保障核心入口与操作。邻舍内部界面继续排除。

## 已落实的布局规则

| 层级 | 规则与实现 |
| --- | --- |
| 全站导航 | 默认 56px 图标栏，保留展开偏好、主题与命令入口；窄屏使用抽屉。原型 52px 调整为 56px，以容纳 44px 点击目标。 |
| 模块顶栏 | PageHeader / WorkspaceHeader 采用 56px 基准；标题、子视图和全局搜索/任务合并。具有 PageHeader 的页面隐藏重复外框工具栏。内容不足宽时允许换行。 |
| 内容工作面 | 20px 外边距、16px 面板间距；持续编辑区独立滚动。目录/设置页面保持自然滚动。 |
| 资料列表 | 320px / 宽屏 336px；搜索与新建同行，选中项清晰，列表滚动与页脚分离。单页隐藏禁用翻页行，计数与容量选项仍可用。 |
| 编辑器 | 48px 基准工具栏；类型、阶段、标签直接编辑，详细属性进入抽屉。保留本机保存、同步状态、手动保存、加入项目与所有真实内容块。收藏/删除收进更多菜单。 |
| 正文 | 760px 外部阅读框，实际文本区域约 656px；正文位置前移，长文自然增长。留白由内容与阅读宽度决定，不用拉伸行宽填满屏幕。 |
| 矮窗口 | 高度不超过 500px 时保留 600px 工作画布、允许文档滚动；笔记工具栏改为普通定位，确保保存可达且不重挂载编辑器。 |

## 本轮验收发现与处理

1. 设置页刷新单独占一行：移入模块动作区；局部刷新保留原职责。
2. 中等宽度资料库相关入口消失：允许换行，保留对话感想与原作档案。
3. 单页笔记显示整排禁用翻页：收为计数与选项，实际多页仍保留完整翻页。
4. 超矮窗口 sticky 保存按钮不进入视口：修正定位；1440×400、844×390、390×320 保存及恢复全部复验通过。
5. 两处新测试定位假设与真实 UI 不符：备份范围改按 combobox 可访问名称定位；分页跳转导致对话框自动关闭时不再点击已不存在的完成按钮，保留页码/数据/URL断言。
