# 前端结构重构与验收（2026-11-04）

本轮已完成源码修改与生产构建，主代理整合并验收，三个 Gemini 3.8 Flash 子智能体并行处理互斥页面范围。没有使用 Terra。保留工作区此前已有改动，未提交、推送或部署。邻舍页面与子模块不在本轮范围内。

## 采用的设计依据

原文：[设计原则](https://ui.daidr.me/guide/philosophy.html)、[视觉语言](https://ui.daidr.me/guide/visual-language.html)。原文快照存于 `artifacts/frontend-design-reset-2026-11-02/`。

落实到本项目的取舍：

- 组件承担结构与行为；颜色、文字、圆角和层级由语义 Token 管理，补齐强调背景上的文字颜色。
- 中性色承担主要界面，状态色表达含义；按文字、表面、细线、浮层阴影的顺序建立层级。
- 控件圆角 6px、普通面板 12px，复杂覆盖层沿用项目的 16px 规格；UI 字重上限 600。阅读内容继续使用独立纸张与字体偏好。
- 依据页面任务调整构图：手机先显示表单与编辑内容，辅助预览、服务统计与低频操作按需展开。
- 原生按钮、输入和菜单必须具有可理解的状态、键盘行为、可见失败提示与恢复入口。
- 原文允许卡片、描边与轻微阴影。本轮保留媒体卡片和有意义的分组，不将“移除所有卡片”作为验收指标。

## 主要结果

| 已复现问题 | 本轮处理 | 复测结果 |
|---|---|---|
| 手机角色名称输入位于首屏外 | 主要表单排在辅助预览前；预览可折叠；压缩页头 | 编辑与新建的名称字段均位于 y≈181px，原为 1221/1169px |
| 角色 Tab 只有外观与点击行为 | 使用统一 PageTabs | 方向键、End 与选中状态通过 |
| 公共资产断图、标签挤压、重复上传入口 | 稳定失败占位、两列缩略图、横向分类与筛选、移除重复入口 | 无可见 broken img；23 条记录保留；搜索 y≈306px，原为 572px |
| 创作首屏由状态与标题占据 | 服务详情折叠、紧凑页头和分栏切换 | 描述框 y≈461px，原为 597px；五种模式与作品/任务均可进入 |
| 出版预览连续请求失败图片 | 固定编译卡片依赖、避免相同 issues 重渲染、显式重试 | 观察 3 秒新增失败请求为 0；重构前 2 秒新增约 398 次 |
| 缺图预览空白且提示在长画布底部 | 提示提前到画布上方，画布占位，镜头画面可重试 | 占位、提示和重试可见 |
| 手机保存失败文字被隐藏 | 顶栏状态可见，增加持续 alert 与重试，保留本地输入 | 两种视口的失败/重试/输入保留通过 |
| 手机排版偏好操作无可见结果 | 改为共享 Dialog，修正覆盖层属性落点 | 弹窗可见、焦点进入、Escape 关闭通过 |
| 活动行菜单 Escape 不能关闭 | 统一 RowActionsMenu，补方向键和焦点恢复 | 手机、桌面均通过 |
| 媒体保存按钮超出内部可视宽度 | 手机保留保存主动作，其余进入菜单 | 按钮右边界约 159px，原为 421px；视口 390px |
| 漫画手机工具栏过高 | 单主保存与次要操作菜单 | 保存与菜单入口完整可见 |
| 设置标题、统计与页签重复堆叠 | 紧凑导航、统计折叠、概览仅在概览页显示 | 服务五页签、生成两层页签、备份四页签均已访问 |
| 备份计划空态排在表单前 | 无计划时手机优先显示新建表单；桌面维持双栏 | 计划名称字段 y≈530px，原为 1306px；最终构建重新采集两种视口 |
| 手机日志列表冗长 | 列表摘要与时间并列，详情保留完整内容 | 同为 50 条时文档高度约 4164px，原为 7206px |
| 列表失败仍展示“空内容” | 活动、档案、日历、素材区分失败/加载/空态，提供读取重试 | 模拟 503 后重试发起请求，失败不再伪装为空 |
| 部分深色按钮文字对比度过低 | 语义前景色、主动作颜色与纸感次级文字调整 | 四主题 × 五代表页的有效文字抽查通过 |

坐标与高度用于同一数据、同一 390×844 视口的前后比较；不单独作为设计合格的依据。截图已经人工查看。

## 验证与证据

- `npx tsc --noEmit` 通过。
- `npm run test:portal`：20 个测试文件全部通过；最终报告 `artifacts/testing/1793774843214-101328/report.md`。
- `npm run build:portal` 通过，生产产物已更新；`git diff --check` 通过。
- 主要修改页面定向 ESLint：0 error、13 warning，主要为原生 img 性能提示和两个未使用变量。另查漫画文件时，存在 4 处 HEAD 已有的同步 Effect 规则错误；本报告不宣称全仓 lint 通过。
- 1440×900、390×844：57 个状态各一轮，共 114 个状态；0 操作选择器错误、0 整页横向溢出、0 可见 broken img。缺失文件的首轮 HTTP 404 仍如实记录。
- 1024×768、1920×1080：故事、活动、出版、创作与角色五种工作区补测。
- `interaction-report.json`：23 项关键行为与多视口断言通过。
- `error-report.json`：档案、日历、素材的失败重试和设置重定向通过。
- `modes-report.json`：16 个内部模式截图，未发现未捕获页面错误。
- `accessibility-report.json`：四主题 × 五代表页的计算颜色抽查；原始记录保留装饰性斜杠，判读时将其排除。不是全站 WCAG 认证。

所有浏览器上下文为隔离环境，DPR 2；手机启用 coarse pointer/touch。涉及临时编辑的验证在浏览器内拦截业务写请求，其余只读浏览，没有写入正式业务库、生成付费任务或运行备份恢复。

临时预览服务已关闭，4173/4280 端口已释放。

证据目录：`artifacts/frontend-refactor-2026-11-04/`。包含脚本、JSON、原图、20 张联系表与三个手机前后对照图。重构前基线在 `artifacts/frontend-completion-audit-2026-11-04/`。
