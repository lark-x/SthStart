# 前端窄屏与入口命名复修

承接[逐页视觉审查](2026-11-15-frontend-page-visual-audit.md)。两位 GPT‑6.1 Sol / medium 子智能体分别负责窄屏页头、模型设置与笔记文案；主代理集成并独立复验。

| 范围 | 改动 |
| --- | --- |
| 窄屏页头 | 页面主操作和全站工具尽量同排，空间不足时按组换行。标题不为容纳工具截字；320px 故事世界可换行，说明在窄屏展开时对齐到页头边界。桌面布局保持原有内容顺序和密度。 |
| 模型设置 | 缩短说明，保留默认继承、按顺序尝试最多两个备用、单独指定应用主模型及看图能力等操作含义。移除看图区容易误读的「主模型不能读图」；配置行为不变。 |
| 资料与笔记 | 「资料库」继续指综合入口，「创作笔记」用于独立笔记页、新建菜单、命令、详情和离线页。旧地址、深链接和查询参数保持有效。 |
| 长选项 | 在有模型配置的 320px WebKit 环境复现：收起的原生下拉框把原本 228px 的内容区撑宽为 301px。将收起的文本限制在控件内，展开菜单用换行保留完整选项名，保留焦点环和独立的菜单定位。 |

[窄屏修复前后对照](../../../artifacts/visual-verification/frontend-audit/followup-compare.html)包含六个代表页面、暖白与暖夜的 24 张隔离样本截图。真实浏览器的验证借助自动化与模拟触控，没有使用物理手机或真实输入法。浏览器测试读取、保存模型与笔记时使用隔离数据，未调用外部模型，也未改动正式数据。

部署前后，390px 的工作台页头实测从 175px 降至 97px，模型设置页头从 204px 降至 116px，项目页从 108px 降至 100px。1024px 和 1440px 的代表页头保持 56px。故事世界在 390px 保持单行工具区；320px 放不下时允许分行，保留完整标题和按钮。

- 视觉矩阵覆盖 12 个代表入口，按三种尺寸和两套主题留图；首轮确认了模型接入与常用模型/应用例外保存、手机笔记详情往返，最终代表页对照已复查实际画面。
