**弹窗可读名称。** 复核结果：「角色筛选与排序」弹窗有可读名称。Mantine 的 `Modal.Title` / `Drawer.Title` 挂载后会自动写 `aria-labelledby`，而共享 `Dialog`、`Drawer` 的 `title` 是必填属性，所以所有经由原语的弹窗都有名称。P0 记录里"没有可读名称"的判断，来自测试按旧标题「角色筛选」查找失败。本轮在采集脚本里实测了 `aria-labelledby` 指向的标题文本，不需要改原语。

**axe 扫描加 390 宽。** `a11y-routes.spec.ts` 改为 1440 / 390 × 暖白 / 暖夜四组。共享测试库里数据变多后（多页列表、媒体、供应商），暴露出 P0 单独跑时没出现的问题，全部在源头修复，没有关闭规则：

| 规则 | 位置 | 处理 |
| --- | --- | --- |
| `label-content-name-mismatch` | 分页「跳页 1 / 2」按钮，名称原为「跳到指定页，当前第…」 | 名称改为以可见文字开头：「跳页 1 / 2，跳到指定页，当前第 1 页，共 2 页」 |
| 同上 | 媒体卡预览按钮，名称「预览 文件名」不含卡内状态文字 | 去掉 `aria-label`，按钮内放读屏专用的「预览 文件名」，缩略图 `alt` 置空 |
| 同上 | 供应商卡主按钮、「详情」按钮 | 主按钮改为内含读屏前缀「管理供应商」；详情按钮名称改为「详情：打开供应商 …」 |
| 同上 | 角色编辑器窄屏「上游采集」按钮，名称为「上游重构 RP 卡」 | 去掉 `aria-label`，名称随可见文字（桌面「上游重构 RP 卡」，窄屏「上游采集」） |
| `color-contrast` | 笔记出处链接在暖夜下用 `text-info` | 改为 `text-info-fg` |

日历格窄屏的读屏名称（「13 苏禾生日，2026-11-13，共 3 项事件」）以可见的日期数字开头，390 宽下没有违规。

## 1. 页面原型组件

新增 `app/components/shared/page-archetypes.tsx` 与纯逻辑 `page-archetypes-model.ts`，只编排现有 `PageContainer`、`PageHeader`、`ReadingContainer`，不新增外框：

- `CollectionLayout`：页头 + 搜索 / 筛选单行 + 筛选胶囊 + 列表 + 底部；`itemCount` 为 1–2 时标记 `data-sparse`。
- `CollectionActions`：1 个主操作 + 最多 2 个次操作 + 溢出菜单；超出预算的次操作自动并入溢出菜单（`splitCollectionActions`）。
- `CollectionFilterButton`（读屏名称 = 可见文字「筛选 (N)」）、`CollectionFilterChips`（逐个删除 + 清除全部）、`CollectionViewToggle`。
- `useCollectionView`：视图状态写在 URL（默认值不写），用 `history.replaceState`，不会冲掉角色库自己用 `pushState` 维护的 `cf` 参数；少于 3 条时强制卡片视图，但保留用户在 URL 里的选择。
- `OverviewLayout`、`DetailLayout`、`ReaderLayout`（约 40em 行宽、1.8 行高、衬线正文）。Detail 与 Reader 本轮没有页面迁移，随 P2 封面一起做。
- 样式在 `app/styles/shell/page-archetypes.css`，只用语义 token。
- 单测 `page-archetypes.test.tsx` 9 项：预算拆分、视图解析与少数据、URL 写回、下一步建议截断、动作区与胶囊渲染、读屏名称、原型标记。

## 2. 页面迁移

| 页面 | 改动 |
| --- | --- |
| 角色库 | 用 `CollectionLayout`。页头：主「新建角色」、次「导入」、溢出「更多角色操作」（RP 卡生成、批量管理、批量获取形象、批量补全、导入本地人设库、批量导入、作品与别名）。筛选行：搜索框 + 「筛选」+ 卡片 / 头像切换；类别、作品、快捷排序并入「角色筛选与排序」面板（面板里原本就有「创作类型」「排序」，不重复）。展示模式从 localStorage 改为 URL（`?view=avatar`）。总数只在分页处显示一次 |
| 制作项目 | 用 `CollectionLayout`。新增卡片视图，少于 3 条自动用卡片；状态页签（活跃 / 已归档）留在工具条；总数只在分页处显示 |
| 媒体库 | 用 `CollectionLayout`。类型、来源、状态三个下拉收进「筛选媒体」面板，生效条件以胶囊显示；保留刷新 |

角色库页头加筛选行的可见控件（不计页签和外框全局工具），按采集脚本实测：

| | 改动前 | 改动后 |
| --- | --- | --- |
| 页头 | 4（新建角色、RP 卡生成、导入、更多） | 3（新建角色、导入、更多） |
| 筛选行 | 11（搜索、全部 / 原作 / 同人 / 原创、作品、快捷排序、更多筛选、头像、卡片、批量管理） | 4（搜索、筛选、卡片、头像） |
| 合计 | 15 | **7** |

筛选、分页、URL（`cf`）、查询键保持不变；相关 e2e（URL 往返、组合筛选与重置、CJK 输入、窄屏页签）全部通过。

## 3. 侧栏 rail

- 收起时 hover / focus 显示文字提示（`shell-nav-tooltip`），以及「展开 / 收起导航」并记住偏好（`sthstart_nav_collapsed`），这两项在分支上已经存在，本轮复核可用，没有重做。
- 图标去重，在 `app/shell/navigation.tsx` 集中定义：「邻舍」`Compass` → `DoorOpen`，「自由生成」`Sparkles` → `WandSparkles`，「AI 创作」→ `Bot`，隐藏路由「剧情」→ `PenLine`、「创作笔记」→ `NotebookPen`。现在每个模块一个唯一图标。
- 「制作项目」（`/apps/activities`）原来在侧栏没有归属项，现在归入「作品」入口的 `activePaths`。页面标题图标仍按精确匹配显示制作图标。

## 4. 首页（OverviewLayout）

- **继续创作主卡**：最近编辑的一项，显示类型、标题、「上次编辑于 N 分钟前」，以及唯一的主按钮「继续」。没有记录时改为「写下第一部作品 / 新建作品」。
- **下一步建议**：最近工作 0–2 条时，显示新建作品、添加角色、记一条笔记三张卡；3 条以上不渲染。
- **统计卡**：图标、模块名、数量同一行，说明放在下一行；卡片高度从约 136px 降到约 64px。数量定宽，位数变化时不换行；手机宽度收起说明。原来 680 字重、12.5px 的写法改为 600 字重和字阶 token。
- **最近工作**：改为带缩略图的卡片网格（模块识别色 + 首字 + 类型角标）。最近工作接口没有图像字段，真实封面和头像随 P2 加入。主卡、建议和列表共用 `HOME_RECENT_LIMIT = 6` 的同一个查询。
