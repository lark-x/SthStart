## 问题与实现

| 反馈 | 原因与处理 | 最终行为 |
| --- | --- | --- |
| 候选生成因 ID 冲突失败 | 模型可能把已有地点 ID 同时用作候选 ID。先检查整批候选和引用，再仅对无人引用的碰撞候选分配独立 ID；有依赖歧义、重复目标、未知来源、循环依赖仍拒绝。提示词明确两类 ID。 | 安全的 ID 复用不再导致整批失败；不重写人物/地点身份或猜测依赖。失败保留草稿、旧候选，人工重试。 |
| 新建世界表单冗长 | 将创建与可运行配置分开；新增迁移 62 `sw_world_setups`、共享契约及鉴权接口。 | 首屏只需名称。服务器保存“待配置”记录，后续补地点和人物；简介、方向、资料、高级项折叠，AI 在辅助抽屉。可以保存部分设定，齐备后“完成配置”原子建立世界和主线。 |
| 切页/刷新侧栏自动开合 | 移除工作台专属临时展开状态，以 HTML 属性承接统一持久偏好，首屏脚本在绘制前恢复。 | 显式选择跨路由、后退、刷新、同源标签页保持；不在加载后动画改变宽度。 |
| 滚动条常驻 | 原滑块样式落在导航列表，旧自动隐藏主要作用于外框；悬停样式也会强制显示。 | 导航空闲/悬停透明，滚动时显示，约 800ms 后隐藏，预留滚动槽避免宽度跳动；高对比度系统保留原生条。 |
| 皮肤菜单过大 | 侧栏移除复杂菜单，设置中心新增“外观”。预览复用真实主题和皮肤变量，隔离祖先皮肤专属阴影。 | 侧栏按钮直接日夜切换；主题、皮肤与主题色在系统设置；每项可预览样例，应用后保存。 |

待配置记录不进入可运行世界列表，不能建立运行分支或绑定项目。完成配置保留原世界 ID；同一次创建/完成请求重试不会重复建世界或主线。部分保存使用修订比较交换；分支写入失败时世界、分支及完成标记一起回滚。旧本机创建草稿仍可从“继续旧草稿”恢复。
