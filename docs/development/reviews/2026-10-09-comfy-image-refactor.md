# ComfyUI 图片生成重构与邻舍对比

## 范围

Sth 的创作中心、角色头像、活动素材槽位、分镜、漫画和放大细化。邻舍仅作为现有源码参考，未修改其子模块。沿用 API JSON / 项目配置包导入，不新增画布 GUI 格式转换器；保留已有预设、用途绑定、默认值和生成历史，没有数据迁移。

## 邻舍是否使用大模型写提示词

**是。**当前固定的邻舍源码版本 `00d5a8b` 中，事件、梦境、朋友圈等业务调用大模型，并通过 `agent-core/src/builtinRules.js` 的 `IMAGE_PROMPT_RULE` 要求输出专业英文图片描述，包括人物身份、数量、动作、服装、空间关系和环境。

需要区分两层：`agent-core/src/services/imagePromptPreparer.js` 的 `prepareImagePrompt` 主要执行知识检索与确定性组装，本身没有再调用一次大模型改写；`imageSkill.js` 的 `buildWorkflow` 把已准备的描述、画师、质量词、负面词、尺寸等注入工作流。

| 影响结果的因素 | 邻舍参考实现 | 本次 Sth 处理 |
| --- | --- | --- |
| 专业提示词 | 业务大模型受图片规则约束，后续组装 | 创作中心/头像增加明确的 AI 准备阶段；活动保留现有优化器 |
| 文本格式 | 通常自然英文描述 | 由工作流版本策略选择标签或自然段，不全局强制一种格式 |
| 画风与质量词 | 工作流注入，空配置可能回落默认 | 自动路径按策略组装；手动最终提示词不再追加 |
| 模型 | 自定义/内置图与覆盖项 | 发布的工作流版本 + 已授权预设；锁定模型成套切换 |
| 采样参数 | 业务默认值和工作流覆盖 | 每个预设按自己的工作流投影范围和默认值，拒绝越界 |
| LoRA | 生成与细化路径的去重优先级存在差异 | 沿用 Sth 活动统一合并与冻结；其他业务由已映射工作流参数控制 |
| 放大细化 | 独立细化配置和默认参数 | 沿用 Sth 冻结原图配置的细化链路，模式切换只改变展示 |
| 失败与历史 | 部分自定义图异常会回退 | 配置冲突、模型失败明确显示；保留原图和参数供重试 |

邻舍的具体画师标签、质量词、步数与 CFG 不能作为所有模型的统一默认值。Sth 已有 Anima Base/Turbo 预设继续使用自身配置。

## 数据与执行链路

1. 按应用、用途、预设及修订解析发布的工作流与连接。
2. 投影该版本的可编辑字段、模型选择权限、画幅、参考图约束和提示词策略。
3. 在调用大模型前校验参数。AI 准备保留描述和审计记录；关闭 AI 或手动编辑时保留原文与显式空负面词。
4. 配置哈希覆盖工作流、连接 ID、提示词策略和预设修订/值。提交时重新解析并比较，拒绝配置漂移。
5. 图片任务记录最终参数与实际种子；有 AI 准备记录时检查应用和工作流归属并关联父调用。创作中心和头像同时记录原始画面描述。
6. 素材槽位、分镜和漫画继续使用已有来源指纹、配置版本、预览/提交及图片历史；新增开关与手动覆盖包含在相应配置中。

新接口：`GET /api/v1/admin/generation/image/options`、`POST /api/v1/admin/generation/image/prepare`。共享 TypeBox 契约位于 `packages/contracts/src/image-generation.ts`；客户端通过管理 API 封装访问，不接收任意上游地址或工作流执行授权。

## 页面行为

- 简单模式保留主要创作动作，高级模式分组显示提示词、模型/LoRA、采样与其他参数。
- 切换工作流采用新方案自身的参数范围；有高级修改时先提示恢复默认，已手动输入的提示词按新映射键保留。
- 草稿恢复完成前禁用表单，避免刚打开页面时输入被覆盖。双击提交有同步锁。
- 修改采样参数不重复改写已经准备的提示词；修改描述、AI 开关或生成方案才需要重新准备。
- 桌面使用预览与参数分栏；手机配置/结果切换保留表单。手机操作区采用正常文档流，避免遮挡输入。
- 头像不自动覆盖已有资产；状态查询暂时失败会继续重试，完成后可重新打开预览并应用。
- 设置页面分项读取，某个诊断接口失败不会使所有已成功读取的配置消失。
- 未设置默认预设时继续使用原用途绑定，不自动选用列表中的第一个预设。配置刷新后需要确认新默认值，已准备的提示词可保留为手动文本。
- 放大细化按来源图片保存会话内的尺寸与重绘幅度，关闭或响应式布局重新挂载后可以恢复。

## 离线验收

```bash
npm run test:contracts
npm run typecheck
npm run build
npm run test:e2e:comfy
node --import tsx/esm --test apps/service/src/generation/image-preparation.test.ts
```

浏览器套件使用临时数据库与模拟 API；测试服务拒绝所有上游模型请求。覆盖模式切换、草稿恢复、手动提示词、AI 失败恢复、工作流范围、手机布局、头像与活动上下文及设置页。服务回归覆盖生成核心、创作中心、头像、活动素材、分镜、漫画、放大细化、幂等和配置冲突。

验收结果：101 项服务测试、40 项契约测试和 10 项浏览器测试通过；类型检查与生产构建通过。桌面和手机截图已检查，手机放大细化采用原图与参数上下排列，避免窄列挤压。

定向 ESLint 对新增共享表单、API、服务逻辑和测试通过。较早存在于漫画、分镜、素材工作台、角色编辑器和活动快捷设置中的 13 项 React lint 错误已用 `git show HEAD:<path>` 对照确认；本次没有把这部分历史问题当作新增失败，也不将全仓库 lint 宣称为通过。

没有调用真实文本模型或 ComfyUI，没有改变真实用户数据库，也没有部署。实际模型的画质、角色一致性与耗时需要在用户环境中以真实生成进一步评估。
