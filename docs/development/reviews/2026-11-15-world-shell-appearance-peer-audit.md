## 实质发现

### F1 · P1：移动导航把日夜切换按钮一起隐藏

**证据**：`app/shell/theme-switcher.tsx:13` 给日夜按钮同时设置 `shell-collapse-btn` 和 `shell-color-mode-btn`。`app/styles/shell/frame.css:138` 对 `.shell-navigation-drawer .shell-collapse-btn` 统一设置 `display: none`。`app-shell.tsx:299` 将此按钮放进复用的 `navContent`，`app-shell.tsx:424` 又把同一内容装入导航抽屉。

**触发与影响**：窄于 1024px 的视口隐藏桌面侧栏；打开手机导航时，日夜按钮因共享折叠按钮类被隐藏。普通页面尚可经外框“更多操作”切换，但故事世界等使用自身 `WorkspaceHeader` 的页面在 `app-shell.tsx:350` 抑制外框工具栏，也失去该外框“更多操作”中的备用日夜入口。嵌入模式同样只复用抽屉导航。此行为由确定匹配的 CSS 选择器可静态推出，尚未浏览器复现。

**建议**：将真正的折叠导航按钮单独标记，抽屉只隐藏该按钮；或给日夜按钮独立的基础样式类，避免被 `.shell-collapse-btn` 的可见性规则连带命中。不要只用覆盖特异性掩盖两种控件的语义混用。

**补验**：390px 下进入 `/apps/story-worlds` → 打开“打开全站导航” → 确认日夜按钮可见、可键盘聚焦并可切换，切换后抽屉状态和焦点符合预期；覆盖两种切换方向。该路径不需要创建世界。

### F2 · P2：从风格化皮肤预览“经典纸感”会继承原皮肤底座（已修，待浏览器复验）

**修复前证据**：`appearance-settings.tsx:78` 在 `sampleSkin === 'default'` 时只省略 `data-ui-skin`。原 `theme.css:14` 的预览基础变量会重置颜色，但没有给 `--card-lip`、`--btn-primary-border`、`--btn-primary-shadow` 等皮肤专用变量设置本地默认值。这些变量仅在 `warm-white-skin.css` 的风格化皮肤规则中声明，例如手账浅色规则的 `:151`、`:153`、`:154`。样例在 `appearance.module.css:29`、`:37`、`:39` 消费这些变量并提供回退。

**触发与影响**：全站使用手账贴纸时预览“经典纸感”，预览容器仍从祖先 `html` 继承 `--card-lip: 2px 2px 0 #24221f`、按钮深色边框和手账底座阴影；由于变量存在，`var(..., fallback)` 的回退不会生效。颜色变成经典纸感，阴影和边框仍是手账效果。点击应用后 `html` 移除皮肤属性，相关变量才不再定义，实际经典皮肤与用户刚确认的预览不一致。原神纪行皮肤到经典皮肤也有相同问题。

**已落地修复**：在 `theme.css` 新增独立的 `:where([data-appearance-preview])` 规则，整组 15 个皮肤专用变量设为 `initial`：装饰色、边框宽度、卡片普通/悬停底座、主按钮边框/底座、次按钮底座、危险按钮边框/底座、按下态底座、开关底座、内胆阴影、弹窗底座、标题分隔线、输入焦点阴影。未注册自定义属性的 `initial` 为保证无效的初始值，阻断祖先继承并允许现有 `var()` 回退生效；该规则的零特异性低于目标皮肤选择器，`genshin/sticker` 仍能正常覆盖。选择器仅命中预览根，不向全站 `:root` 添加默认皮肤变量。

**已做静态检查**：使用现有 PostCSS 解析两份样式，确认预览重置的 15 个变量恰好覆盖 `warm-white-skin.css` 中仅皮肤定义的整组变量，且四种目标皮肤/日夜组合均声明完整变量集；CSS 解析及限定文件的 `git diff --check` 通过。没有运行构建、测试或浏览器；计算值和最终视觉仍待主代理复验。

**补验**：分别应用 `sticker` 和 `genshin` 后预览 `default`，检查样例卡片和按钮的实际阴影/边框与干净经典皮肤相同；取消后全站属性、localStorage 和全站计算样式不变；应用后检查预览对应的外观结果与实际一致。再覆盖浅色和深色模式，以及已有自定义强调色的情况。

## 已核实的正向静态证据

- 预览入口只修改局部 `preview` 状态；主题/皮肤 setter 只位于“应用”回调，未发现预览点击直接写全站偏好的路径。原 F2 为全站皮肤变量流入样例，现已增加预览根隔离，实际计算样式待主代理复验。
- 收起导航的 `.shell-nav-text` 使用视觉隐藏规则保留文字；品牌链接另有 `aria-label`。没有把收起后的导航误报为无可访问名称。
- 侧栏全局收起偏好由 HTML 属性承接，首屏脚本读取持久值；点击先更新属性，再通知订阅者。实际导航链接、分组及图标的 CSS 都通过该 HTML 属性同步决定可见形态。
- 导航专用滑块规则位于通用 hover 规则之后，并带有强制颜色模式回退；就选择器而言，停手后继续悬停不应使导航滑块常驻。最终绘制和设备滚动行为仍需主代理验收。
