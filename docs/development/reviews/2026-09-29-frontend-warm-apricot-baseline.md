## 第二轮全站视觉补强与部署（2026-09-29）

### 本轮确认的根因

- `theme.css` 中 Tailwind `@theme` 语义色曾作为单独样式表从布局导入，脱离 `globals.css` 的 Tailwind 编译图；导致 `bg-accent`、`text-ink` 等一批语义工具类没有生成。主按钮、文本层级和表面色因此未按既定 Token 呈现，是“改了视觉但看起来变化不大”的直接技术原因。
- 已将 `theme.css` 纳入 `globals.css` 的 Tailwind 导入链，并从布局移除重复导入；实测生成 CSS 包含相关语义类，文字对比度、焦点、控件边界和暖杏/中性主题测试恢复通过。
- 全站 `.shell-*` 与 `.tpl-*` 共用的导航、页头、面板、表单、按钮、抽屉、徽标和状态外观同步调整。活动、角色、资料库、日历、话题、剧情、叙事、创作中心、AI 日志与控制中心采用对应组件类；没有更改业务 API 或数据格式。
