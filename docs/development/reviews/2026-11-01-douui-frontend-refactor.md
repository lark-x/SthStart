# DouUI 原则驱动的前端重构

参考资料：

- [DouUI 设计原则](https://ui.daidr.me/guide/philosophy.html)
- [DouUI 视觉语言](https://ui.daidr.me/guide/visual-language.html)

本次将参考原则应用于现有 React 前端，保留暖纸基调、四种主题、已有路由及业务能力。

## 设计落点

1. `app/styles/theme.css` 是全局语义变量的定义源，组件引用用途明确的表面、文字、边框、操作与状态变量。主操作使用随主题切换的中性色，强调色只表达有限的语义。
2. 首页、普通列表及设置使用自然文档流；长时间编辑的工作台在可用视口内独立滚动。布局原语共同约束尺寸与信息层级。
3. 共享控件保留原生表单属性与事件，默认按钮避免意外提交，加载状态有可访问语义，中文输入法合成期间不触发应用快捷操作。
4. 文字、表面与细线优先表达层级，浮层才使用明显阴影。键盘焦点、减少动效和窄屏触控属于组件默认行为。
5. 写作纸张是明确的内容阅读偏好，通过局部变量作用于正文，不改变全局工具界面。

## 并行边界

| 责任 | 范围 |
| --- | --- |
| 设计系统 | 全局主题、基础样式及 UI 控件 |
| 普通页面 | 导航外框、首页、共享页面布局、普通列表与设置 |
| 创作工作台 | 活动、剧情、角色、图像界面与工作台布局 |
| 主代理 | 跨模块审查、主题预览一致性、检查与验收交付 |

实现使用最多三个并发子智能体；界面验证单独由 GPT-6.1 Terra / medium 负责，避免多个智能体同时操作同一浏览器。

## 验收要求

- 类型检查、门户测试和生产构建通过；新发现的错误区分为本次回归、原有问题和环境限制。
- 检查首页、普通列表、设置以及真实测试对象的活动/剧情工作台。
- 覆盖 1920×1080、1440×900、1024×768 和 390×844；检查横向溢出、标题语义、主要操作和导航可达性。
- 四主题检查文本与交互状态，长正文检查外层高度及内部滚动；中文输入法候选确认不应触发保存或关闭。
- 菜单键盘导航、Escape、焦点恢复和减少动效需要实际验证。工作台侧栏或抽屉切换不应丢失草稿。
- 截图必须查看实际图片后评价，不把脚本退出成功等同于视觉通过。

## 主代理实际验收

浏览器操作由 GPT-6.1 Terra / medium 单独执行，主代理检查 JSON 证据、实际查看截图并修复缺陷。证据目录为 `artifacts/frontend-douui-2026-11-01/live-acceptance/`。

已完成并审阅：

- 四主题切换，目标主题精确匹配；Escape 关闭主题菜单并恢复焦点。
- 命令面板打开、IME 合成期间回车不误执行、普通 Escape 关闭。
- 6,700 余字剧情章节的编辑、侧栏折叠后草稿保持、保存并刷新后内容仍存在。
- 活动加场、添加分镜、编辑对白，保存草稿接口返回 200，刷新后对白仍存在；侧栏折叠后草稿保持。
- 桌面工作台外层没有多余滚动，内部有独立滚动区域。
- 两个实际测试角色的手机列表，包括长名称卡片；手机工作台、首页和桌面活动截图人工复核。

本轮发现并修复：

1. 手机首页完整主题名挤压标题：改用紧凑主题入口，完整主题仍可从菜单选择。
2. 手机工作台业务操作挤压对象标题：导航和任务保留首行，业务操作另起一行。活动标题编辑宽度从 90px 增至 210px；剧情顶栏高度从 191px 降至 141px。
3. 手机分镜缩略图压缩对白编辑区：缩略图移到正文下方，对白编辑宽度达到 288px；加镜与删除操作在触控界面常显，保留 44px 热区。
4. 分镜编辑的 Shift+Enter 增镜快捷键补充 IME 合成保护。浏览器确认合成期间不增镜、普通 Shift+Enter 正常增镜；分镜角色、对白和动作字段补充明确可访问名称。
5. 叙事档案独立阅读模式缺少主内容地标：阅读模式根节点改为 `main`，普通研究与导入模式继续由页面外框提供地标。
6. 1024px 活动三栏同时展开使对白过窄：768–1279px 默认收起镜头工坊，保留用户展开选择；场次标题在窄栏可收缩，避免与添加分镜按钮重叠。
7. 创作笔记的新建页与编辑页作为嵌入工作区时缺少 `main` 地标：聚焦编辑态改用 `main`，列表与离线入口继续使用外框地标。

早期错误后端配置的截图和旧手机布局已被后续复验替代；部分探索脚本曾出现错误选择器，失败记录保留，不能当作产品缺陷或通过证据。有效专项结果以 `step1-story-report.json`、`step2-activity-report.json`、`step4-activity-panel-draft-report.json` 和 `retest-mobile-fixes-report.json` 为准。
