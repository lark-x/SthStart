# 出图配置：简单与专业模式评估

日期：2026-10-13

依据：当前工作区源码；邻舍实际检出 `6b4c2e517ef72eb606a6ea3577c11804c3a6c603`。本文评估配置与交互，不评价真实画质；本轮未修改业务代码或配置数据。素材及旧分镜面板区分“组件已有能力”和“当前页面可达能力”。

## 判断

建议所有出图入口统一为“简单模式 / 专业模式”。简单模式围绕画面内容和已配置方案；专业模式提供本次任务的精确控制。生成配置中心另行管理可复用方案、用途默认和运行环境，不作为第三种出图模式。

简单模式应能完成角色、服装、世界观、参考图和构图选择。它们是创作需求，不能仅因为实现涉及复杂模型就藏到专业模式。专业模式也应保留这些内容选项，在同一份草稿上展开控制。

模式切换只改变可见控件。Base/Turbo、草图/成稿、文生图/图生图、细化工作流切换会改变生成行为，应作为独立选择。

## 需要统一的语义

1. **方案、画风、输出尺寸分开。** 生成方案包含兼容的工作流、模型与采样；画风表达画师、质量标签、风格 LoRA 等配置；输出尺寸单独选择。简单模式使用具名选项，显示一行实际摘要。
2. **Base/Turbo 和草图/成稿各有含义。** Base/Turbo 是技术方案；草图/成稿是产品档位，映射由管理端配置。当前显式选中单次预设后，品质档位不会再选择活动档位预设，不宜让两个选择器都看起来在控制同一件事。简单模式建议只显示一个“生成方案”入口，可用“快速草图 / 精细成稿”作为配置后的显示名称，不硬编码固定模型或耗时。
3. **内容选择始终可达。** 角色、服装、lore、参考图、景别、光影属于内容；LoRA 文件/权重/触发词属于执行控制。简单模式可选择角色和画风，自动继承其 LoRA，专业模式才调权和覆盖。
4. **自动整理与最终文本分开。** AI 整理描述、世界观引用、图片标签知识、画风/触发词追加分别说明。采用手动最终词后明确停止哪些自动处理，并保留“恢复自动组装”。知识补全模式由兼容方案/策略默认提供，专业模式按支持能力覆盖。无 AI 的自动组装应继续保留角色/lore 语义，避免“关闭改写”被误解为“丢弃来源”。
5. **继承、覆盖、清空分开。** 负面词等字段同时提供“继承默认 / 本次覆盖 / 明确清空”，不依靠输入框空白猜测。配置标明作用范围：此图、此镜头/画格、此活动、此用途或角色默认。

## 建议字段分层

| 配置 | 简单模式 | 专业模式 |
| --- | --- | --- |
| 画面来源、描述和补充要求 | 可编辑；活动自动带入动作和场景 | 同一内容，允许查看来源与覆盖 |
| 角色、服装、世界观 | 选择或显示继承摘要；活动默认绑定，头像固定角色 | 查看版本、来源和有效服装，处理明确覆盖 |
| 参考图 | 上传/选择，显示用途与是否支持 | 参考角色、影响强度、重绘幅度等已声明能力 |
| 构图、景别、角度、光影、氛围 | 少量常用项，按模块显示 | 完整内容控制及可用的额外约束 |
| 画风 | 画风卡/收藏，不要求输入技术文本 | 原始画师/质量词、风格 LoRA 和触发词 |
| 生成方案 | 具名方案，默认自动选择 | 工作流版本、预设修订、支持的模型覆盖 |
| 画幅与候选数 | 用途适配的画幅；批量显示候选数与总张数 | 自定义像素、batch 等已声明参数 |
| 提示词处理 | 自动整理默认开启，可关闭；显示手动文本状态 | 最终正负词、组织协议、知识模式、处理诊断 |
| 模型、LoRA、采样、seed | 读取方案，展示简短有效摘要 | 按支持能力编辑，显示继承与锁定原因 |
| 错误和未就绪 | 影响提交的原因始终可见 | 展开技术详情、实际参数和任务追溯 |

专业面板建议固定为“提示词、模型与 LoRA、采样与尺寸、来源与诊断”四组。平台连接、密钥、节点映射、任意工作流 JSON、发布/用途绑定留在配置中心。

## 已确认的不一致

- 通用面板用字段名正则筛选和分组；应优先使用既有语义/section 元数据，必要时补明确可见级别与组别，避免自定义工作流字段被错误归类。
- 通用面板的高级参数计数包含简单模式修改的 width/height；活动计数主要只看 parameters 与 finalPositivePrompt，漏掉 LoRA、负面词、参考图等隐藏修改。应统一按“当前隐藏且偏离有效默认的配置”计数，并列出具体项。
- 通用面板“模型与 LoRA”组只呈现工作流字段，角色自动合并的 LoRA 主要出现在只读诊断；活动面板可按图关闭/调权，专业能力不同。需提供一致的有效 LoRA 列表及能力允许的本次覆盖。
- 专业模式中的工作流切换与生成方案选择存在重复；可将工作流作为方案详情，只有要选其他图时再展开。
- 通用面板有硬编码情境画风，活动另有版本化画风卡，邻舍有画师收藏；推荐形成共用画风选择和收藏入口，并在专业模式展示实际构成。
- 当前活动设置抽屉没有挂载 ArtDirectionDialog；虽顶栏提示画风预设，实际内容主要是活动基本资料、演员和幕次。需要明确的活动美术配置入口。
- 邻舍 HiresFix 的基础/进阶切换会改变图和依赖；本项目模式切换原则是不改变已填写配置。专业模式不能默认切换更重的算法。

## 实施顺序建议

1. 统一名称、配置语义、继承/清空状态及隐藏修改摘要；完善所有用途的默认配置入口。
2. 以共用生成面板为基础，建立业务内容区和技术参数区；头像做用途裁剪，工坊保留自由配置。
3. 在当前活动工作台接回素材、美术配置、分镜专业控制、历史和细化；漫画同步内容/参考图分层，批量生成共用方案解析。
4. 在现有能力范围内统一 LoRA 和细化控制；支持的范围由真实工作流和实例返回，缺少能力时明确说明。

验收重点：相同草稿切换模式后的执行输入不变；隐藏覆盖有完整摘要；恢复继承不删除作者内容；所有模块实际配置来源可追溯；窄屏能完成简单模式的生成和结果选择。
