## 1. 第 0 步：P3 遗留

### 1.1 「来源更新预览」：真缺陷，已修复

- **现象**：沙盒视图在 1152px 以下点「查看影响」后，「纳入新版资料前的影响预览」对话框不出现。
- **原因**：`SourceUpdatePreview` 的对话框渲染在筛选栏内部。窄屏时筛选栏是底部抽屉（`WorldFilterRail` 的 `Drawer`），抽屉一关，对话框随它一起卸载。不是入口挪了位置，而是功能在窄屏下失效。
- **修复**：`app/features/story-worlds/components/source-update-preview.tsx` 让预览对话框脱离筛选栏的挂载位置，抽屉关闭不再影响它。
- **验证**：`story-worlds-source-updates.spec.ts` 原用例在对话框打开时把窗口从 1440 缩到 390，正好覆盖此场景。重新构建后单跑通过，用例上方的「待排查」注释已改为上述结论。

`npm run check:ui -- --update` 已收紧基线，现在只剩 2 个文件有存量。剩下 4 处任意像素值是有意保留的几何值：`playback-preview-screen.tsx` 手机外框的 36px / 24px 圆角（模拟设备外形，不是界面圆角），`ai-logs-client.tsx` 时间线圆点的 `-left-[21px]` 定位（对齐 `border-l` 与 `pl-4` 之间的像素位置）。

### 2.2 怎么替换的

- **状态色**：emerald/green/teal → `success`，amber/yellow/orange → `warning`，red/rose → `danger`，sky/blue/cyan/indigo → `info`。浅底与半透明底 → `bg-*-bg`，实心底 → `bg-*-solid`（文字同时改为 `text-*-on-solid`），文字 → `text-*-fg`，边框与 ring → `*-border`。
- **识别色**：类别/类型配色（`reading-utils.ts`、`badges.tsx`、任务抽屉的任务类型图标）改用 `--tone-*`：浅底 `bg-tone-*-soft`，文字 `text-tone-*-fg`，边框 `border-tone-*/30`。purple/violet/pink 在其他文件里也走识别色，不冒充状态色。
- **中性色**：slate/gray/zinc/stone 按明度改为 `fg-default / fg-muted / fg-subtle`、`surface-sunken / surface-muted`、`border-subtle / default / strong`。
- **深色孤岛**：`prompt-source-panel.tsx`、`image-impact-review.tsx`、`playback-preview-screen.tsx`、`story-agent-connect-dialog.tsx` 原来在任何主题下都是固定深底，在暖白主题里是一块突兀的黑板。现在跟随主题使用表面层级，四套主题下都与周围一致。
- **媒体遮罩**：图片/视频上的 `bg-black/*`、`text-white` 改为新增的 `--media-backdrop`、`--on-media`（四套主题共用，因为媒体本身不随主题变）。
- **`dark:` 变体**：语义 token 已随主题切换，旧的 `dark:text-*-300` 一并删除。
- **选中标记**：角色素材选择器与多源导入的勾选角标原来用识别色或白字，改为 `bg-accent` + `text-fg-on-accent`（强调色表示「已选中」）。
- **hex**：自定义强调色的 5 个预设色票是用户可选的数据值，移到 `app/lib/theme-preference.ts` 的 `ACCENT_PRESETS`；漫画画布的选中框读取 `--danger-solid` / `--success-solid`；发布卡片导出图的占位色与纸色改为 `theme.css` 中的 `--publication-*`（内容色，四套主题一致）；邻舍状态胶囊改用识别色；日志/控制台文字改用已有的 `--console-fg`。
- **字号与字重**：`text-[9–11px]` → `text-xs`（12px），`font-bold/extrabold/black` → `font-semibold`。主题里 bold 早已映射为 600，字重改动不改变外观，只消除误导。
- **任意像素值**：2px 整数倍的值改用 Tailwind v4 间距刻度（如 `max-w-[180px]` → `max-w-45`，数值不变）；8/12/16px 与 6/18px 圆角改用 `--radius-*`。
- **字符图标**：3 处「↗」改为 Lucide `ExternalLink`。

替换中发现并修复：自动去重时误删了 `beat-render-workbench.tsx` 两处模板字符串里重复的 `?` / `:`，类型检查报错后按 HEAD 原文重放修复；随后对所有改动行比对 `?`、`:`、引号与 `${` 数量，没有其他被误删的位置。
