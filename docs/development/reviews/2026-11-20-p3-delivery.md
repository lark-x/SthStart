## 4. 动效语言

共享实现在 `app/styles/motion.css`：

| 场景 | 实现 | 接入 |
| --- | --- | --- |
| 列表首次出现 | `list-item-in`：淡入 + 上移 4px，`--motion-base`，第 n 项延迟 30ms×(n−1)，第 9 项起与第 8 项同时 | `[data-collection-items]`（页面原型列表：角色库、制作项目）与 `[data-motion-list]`（首页最近工作、下一步建议、模块卡、近期日程、媒体库网格） |
| 面板 / 标签切换 | `tab-panel-in` 改为淡入 + 横移 4px，`--motion-fast` | 所有 `[role='tabpanel']`（PageTabs、Mantine Tabs） |
| 浮层 | 共享 `Dialog` 自定义过渡：透明度 + 缩放 0.98→1，`--motion-ease` | 全部 `Dialog`；减少动态效果时由 `useOverlayTransitionDuration` 置 0 |
| 保存状态 | 文字颜色过渡 + 图标淡入 | `SaveStatus` |

- 动画用 `backwards` 填充：等待错开期间停在起始帧，结束后回到普通样式，不保留合成层，静态截图与改动前一致。
- `prefers-reduced-motion: reduce` 时，以上全部关闭并直接显示。
- 没有新增 `:active` 位移，Skill 里关于 `scale: 1` 的规则写进了接入说明。
- `tests/e2e/motion.spec.ts`：
  - 允许动效时，角色库三项依次 0s / 0.03s / 0.06s，首页第 3 项 0.06s，标签面板关键帧为横移 4px；
  - 减少动态效果时，列表、面板、保存状态均为 `none` / `0s`，内容不透明度为 1。
