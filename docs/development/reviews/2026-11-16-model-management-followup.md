# 模型管理续作验收

日期：2026-11-16。依据原会话「规划模型与服务配置简化」及 [供应商、多类型模型与联网搜索统一](2026-11-15-suppliers-search-unification.md)。

## 现状与本轮修复

当前实现已包含常驻供应商列表、零模型供应商、按同一地址归组的历史连接，以及文本/看图、向量计算、绘图三类模型。本轮补齐持续管理的交互和异常路径，没有新增数据库迁移或改变共享接口。

- 详情、编辑、添加模型使用独立 React key，避免同级组件 key 冲突产生残留弹窗。进入子操作时释放详情弹窗，返回保留用途标签。
- 编辑合并供应商仅同步实际修改的字段；其他历史连接的名称、地址、超时、请求头和额外参数各自保留。密钥留空仍保留原值。保存中锁定字段，部分连接失败时刷新已成功的结果并保留草稿。
- 新增模型优先选择已启用的兼容连接，再比较协议用途，避免停用的历史绘图连接遮住可用的 OpenAI 连接。
- 切换模型用途使旧目录请求失效，并清空旧用途的临时输入和能力选择。
- 批量保存记录成功项；即使刷新列表也失败，重试仍只提交失败项，不重复新增成功模型，错误文案保留部分失败事实。
