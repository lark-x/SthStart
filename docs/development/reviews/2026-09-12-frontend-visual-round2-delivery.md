本次沿用项目的本地 Docker 网站，仅替换门户构建产物，没有迁移到新的云端站点。`.openai/hosting.json` 保持原样。Sites 构建辅助脚本在本机遇到 npm 路径解析问题，改用项目原有构建命令完成验证。

容器内保留修改前门户构建目录 `/app/dist-before-visual-round2`。当前 `/app/dist` 为新门户；保留旧哈希静态资源，以降低已打开标签页遇到资源缺失的可能性。源码改动保存在工作区，后续重建 Docker 镜像时会正常带入。

旧版回退时，应先备份当前构建，再将上述备份恢复到 `/app/dist` 并重启本地容器。这个备份位于容器内，删除或重建容器前如需长期保留，应先导出。
