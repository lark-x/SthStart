# B 方案：Web 工作区统一改造与基础功能补全计划

状态：用户已确认；B 布局与本轮基础功能改造已实施，隔离浏览器验收已通过并部署。具体覆盖、证据和未验证边界见 [验收记录](2026-11-08-b-final-acceptance.md)。下文保留原方案，不将方案要求自动视为已逐项验证。

## 1. 已确定的方向

- 采用用户选定的 B 原型：窄导航、独立工作面、柔和底色、面板间距区分主区域。
- 桌面 Web 为主要使用场景，优先 1440×900、1920×1080，兼容 1280×720 和浏览器缩放。
- 移动端只承诺核心浏览、搜索、简单记录、保存与任务查看；不压缩复制桌面复杂制作台。
- 布局和皮肤分离：所有主题使用相同导航、面板、分页与操作结构。暖夜保留认可的配色；不使用绿色主色。
- 原型是布局方向，演示文字、数量、已归档等示意入口不自动成为真实功能要求。正式界面保留产品原文与真实能力。
- 邻舍保留独立应用内部设计，仅核对入口及外围导航。

## 3. 全站布局规则

### 导航与标题

- 桌面默认窄图标导航，提供展开成文字导航的开关并记住偏好；图标提供悬停说明、键盘焦点和当前模块标记。
- 顶栏仅放全局搜索、任务与必要的全局操作，不重复模块标题。
- 每页一个主标题、一个主要操作；分类标签位于标题下方。帮助说明仅在有实际用途时保留。
- 页面级操作、列表筛选、文档编辑操作分别归属于各自区域，不能混放到同一条工具栏。

### 面板与分隔

- 外层画布使用柔和底色；主要工作面采用统一的轻圆角面板。
- 两个独立工作面之间以 16–20px 间距分隔；同一面板内部用细分隔线或留白分组。
- 不在编辑面板内部再包一层装饰性纸张，不把每一个设置项都装进卡片。
- 搜索/筛选固定在列表面板顶部，分页固定在其底部，只有结果区域滚动。
- 属性默认折叠，通过明确入口打开；较宽屏幕使用侧面板，较窄屏幕使用覆盖抽屉。打开属性不得丢失草稿或挤掉保存入口。
- 只在需要比较内容的工作台提供拖拽分栏；支持键盘调整、双击复位、最小宽度、记住比例。分隔条默认低对比度，悬停/聚焦时清晰显示拖拽提示。

### 页面模板

1. 列表/资源页：标题 → 搜索筛选 → 卡片或列表工作面 → 分页。
2. 文档编辑页：列表面板 + 正文面板；正文顶部工具栏，属性按需展开。
3. 生成/制作台：配置面板 + 结果/预览面板；任务与历史为同区域标签。
4. 设置页：分类导航 + 分组表单，明确保存状态；长表单正常滚动。

统一的是规则与组件，不是每个模块都强制相同列数。

## 4. 分页与查询标准

- 总量与范围，例如“共 128 条，当前 21–40 条”；页码、上一页、下一页、首尾页、跳页；无数据时明确显示 0 条，不显示 1/0 页。
- 文本列表默认 20 条，选择 20/50/100；图片网格默认 24，选择 24/48/96。后端须校验上限；大内容列表可降低单页容量。
- 页码较多显示首尾、当前邻近页与省略号；资料窄栏提供紧凑版本，跳页与容量放入弹出面板，禁止挤压按钮。
- 搜索、过滤、排序或页容量改变时回到第一页；每次查询的总数必须对应当前筛选。
- 删除末页最后一条后回到有效页；越界 URL 自动纠正；非法页码不触发错误页面。
- 明确排序键并以唯一 ID 补充稳定排序，避免同时间记录跨页重复；实时新增内容提示刷新，避免用户浏览时突然换位。
- 请求中显示更新状态，保留已有结果但避免将旧数据标记成新页；防止旧响应覆盖新筛选。失败显示重试，不伪装成空列表。
- 页码、查询、排序、筛选进入 URL；页面容量与布局偏好可本地保存。刷新、浏览器前后退、详情返回恢复列表上下文与滚动位置。
- 搜索查询全部符合权限的数据，不只过滤当前已加载一页。
- 批量操作默认“选择本页”；跨页选择显式显示累计数量。若支持“全部筛选结果”，必须单独说明范围，禁止模糊全选。
- 选择器也采用相同规则，不能主页面能找到、弹窗却因固定上限找不到。
- 未同步草稿独立提示数量与状态，不冒充服务器分页总量；明确本地搜索与已同步全量搜索的边界。
- 任务流和生成历史可用加载更多；无可靠总数时不提供虚构页码和总页数。

## 5. 其他基础功能补全

- 搜索：清空、无结果提示、已生效筛选标签、一键重置、合理防抖、中文输入法兼容。
- 表单：字段标签、必填提示、就地错误、提交中反馈、防重复提交；失败保留输入。
- 保存：区分未保存、保存中、已保存到本机、同步中、已同步、失败和冲突，不用一个“已保存”掩盖差异。
- 离开编辑：保护未持久化内容；刷新、切换条目、切换模块和关闭属性面板不丢稿。
- 新建/编辑/删除：操作成功后更新列表、总数与选中项；删除确认明确对象与引用影响。没有恢复能力时不承诺撤销。
- 资源引用：选择、加入项目、查看来源、解除关联有明确反馈；解除关联与删除源文件区分。
- 加载/错误/空态：分别处理首次空库、搜索无结果、无权限、服务未配置、网络失败、资源失效；给出相应下一步。
- 任务：根据服务真实能力开放取消、重试、查看错误和结果跳转，防止重复生成或重复计费请求。
- 键盘：Tab 顺序、可见焦点、Esc 关闭浮层并还原焦点；Ctrl/Cmd+K 搜索，编辑器 Ctrl/Cmd+S 保存；不覆盖中文输入法组合键。
- 性能：媒体缩略图按需加载，长列表分页，大量任务不阻塞编辑；返回列表避免无意义重载。
- 危险操作：删除、清空、覆盖、恢复备份分别表达后果；只在真实需要时确认，不为普通查看和切换增加阻碍。

## 7. 移动端范围

支持：导航、搜索和翻页；项目概览与正文阅读；资料、角色、媒体详情；简单文字记录与保存；任务状态、错误与结果查看；日历基础查看。

有限支持：复杂角色长表单、生成参数配置、分镜/批量制作、工作流与数据源配置。保留可安全完成的已有操作；不在本轮追求手机与桌面功能对等。不适合窄屏的操作说明建议桌面使用，不能只展示被裁切的界面。

手机使用列表→详情的单栏切换，属性抽屉与底部操作按需出现。最小验收尺寸 390×844，补查 360px 宽；键盘弹出时保存可达。

## 8. 实施顺序与交付门槛

1. 基线盘点：建立所有路由、标签、弹窗、关键动作清单；记录现有行为和待验证问题。
2. 共享基础：B 外框、导航、面板、分隔、分页、查询状态、操作反馈。布局脱离主题选择器。
3. 两个样板：资料库与创作项目，使用超过三页的代表数据；同时展示暖白和暖夜，确认统一规则后推广。
4. 资源模块：角色、媒体、灵感、任务及各选择弹窗；分页需求同步落实到接口，保留兼容性。
5. 创作与系统：正文、制作台、自由生成、日历、设置、兼容入口与公共浮层。
6. 回归与交付：桌面核心流程、分页边界、移动端有限范围、各主题同布局回归；汇总通过/失败/未验证事项，再部署。

样板阶段若发现对原型的实质性偏离，先展示差异；常规实现按已确认规则继续，不每个小步骤重新申请。

## 9. 验收标准

- 路由清单每项有桌面结果，不能仅覆盖主导航首屏；浮层和详情也要覆盖。
- 分页使用 0、1、整页、整页+1、超过三页的数据，测试跳页、首尾页、容量变化、筛选后不足一页、末页删除、失效页码。
- 在后续页搜索仍能找到记录；选择弹窗能找到初始读取上限以外的对象；页面总数与查询结果匹配。
- 测试慢请求、失败重试、快速改筛选、返回/刷新、跨页选择；旧响应不能覆盖新状态。
- 完成“项目→正文→引用资料/角色→制作→查看结果”的可用流程。涉及外部生成服务的步骤按实际环境明确通过或未验证，不用演示结果冒充。
- 页面只有一个主标题，无重叠、裁切、双重滚动问题；分隔拖动不改变数据、不遮挡关键操作。
- 主题切换前后面板尺寸、顺序和按钮位置一致；暖夜保留原配色。
- 验证真实 HTTP 与内容，查看截图并进行交互，构建和自动检查通过不能单独代表完成。
- 测试在隔离库中造数据；正式数据只读检查，部署前备份。不得用生产库做批量删除、故障或恢复测试。

## 10. 本轮不承诺新增的能力

不新增权限体系、多人协同、云同步、全局回收站；不因原型出现示意标签就新增归档业务；不重做邻舍内部、不扩展新的 AI 业务。已有基础功能缺失会修复，但影响数据模型或超出范围的新能力单独列出。
