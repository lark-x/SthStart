## 2. 沿用的方向与边界

沿用用户选定的B方案：全局导航、列表、内容的工作台布局；桌面优先，暖夜及其他现有皮肤共用几何结构。本轮规划不换配色、不重做数据模型、不删资料或入口，不扩展邻舍内部。

资料库主任务为“找资料→读/编辑内容→引用到项目”。默认进入有内容的工作区；属性、来源管理、整理动作按需展开。少量内容留下自然余白是正常状态；要求消除挡在任务前面的空白与重复工具行，不用虚构内容、拉宽短段落或塞满面板提高占用率。

## 3. 目标结构

桌面从上到下只保留三层：

1. 全局导航：负责跨模块移动；尊重用户展开/收起偏好，不强制收起来制造面积改善。
2. 模块顶栏：一行“资料库｜笔记 / 灵感素材｜搜集任务｜资料管理｜全局搜索 / 任务”。模块说明改到帮助入口或首次空态；不常驻第二行大标题。
3. 工作面：左侧列表工具与结果，右侧当前文档及其操作；可选属性侧栏仅在打开时占位。

页面初稿应呈现以下关系：

```text
全局导航 │ 资料库  笔记 / 灵感素材       搜集任务  资料管理   搜索  任务
         ├─────────────────┬─────────────────────────────────────
         │ 搜索   筛选  ＋  │ 已同步             加入项目  属性  更多
         │ 全部  收藏  待整理│ 文档标题
         │ 选中的资料       │ 日记 · 草稿 · 标签（紧凑摘要，可编辑）
         │ 其他资料         │
         │                 │ 正文直接开始，工具在块侧或焦点处出现
         │                 │
         │ 共N条  分页/容量 │ ＋ 添加内容
```

这只是结构线框；具体顶栏分组、行宽与不同宽度的换行行为以第一阶段可操作原型确定。

| 区域 | 调整 | 保留的能力与规则 |
| --- | --- | --- |

| 资料库导航 | 笔记/灵感作为内容切换；待整理进入列表状态过滤；搜集任务作为独立任务入口；数据源与原作档案/对话感想进入有文字的管理/相关资料分组 | 不静默删除能力；旧URL仍可直达并能返回原筛选上下文 |
| 新建与折叠 | 新建放到列表搜索旁，折叠放在列表边缘或列表头 | 不再为两个按钮占据跨整页空行；折叠后保留明确展开入口 |
| 列表 | 搜索常驻，常用状态一行；分类/标签/高级筛选合并面板，选中条件外显为可移除摘要 | 搜索与筛选对象清晰；筛选后重置页码，保留有效每页容量 |

| 文档工具栏 | 同步状态与文档动作同一行；加入项目可见，属性与更多有文字标签 | 保存逻辑先保持现状；有改动/失败/离线时保存入口和状态不能隐藏，不冒然改为新的自动保存策略 |
| 标题与元信息 | 标题后保留一行分类/阶段/标签摘要，点击编辑；资料属性移至按需侧栏/抽屉 | 未确认、来源、引用等重要状态仍有紧凑提示；长标题自然换行 |

| 面板边界 | 用背景层级和一条清晰分隔表达列表/文档/属性，不重复叠卡片或阴影 | 边界可辨、分栏可调整；颜色只取现有主题语义值 |

## 5. 空间分配目标

以下是待原型验证的目标值，不是现有测量结果。以CSS像素及浏览器内容区计算，不计地址栏和书签栏。

- 1440×900：模块顶栏约48–56px，列表/文档工作面顶部距网页顶不超过96px。短标题、默认属性收起状态下，正文第一行距网页顶不超过240px；超过时逐项解释必要内容。
- 1280/1440/1920的常用桌面均对照；展开导航状态必须达标，另测折叠状态。
- 列表初始宽约280–320px，允许调整并设合理边界；文档工具跟随文档区，不漂浮在整个页面另一端。
- 正文以约45–55个中文字符的舒适行宽为起点；默认靠文档区左侧留24–40px内边距。超宽屏剩余空间供主动打开的属性面板使用，不能硬拉长文字行。专注阅读模式可居中。
- 正文区域高度尽量达到视口的70%以上（默认短标题与折叠属性状态）；该指标指可用于内容的空间，不要求短笔记填满它。
- 长标题、错误提示、离线状态优先完整表达，不为像素目标截断必要信息。
- 只保留一个内容区域纵向滚动容器和一个列表滚动容器；矮视口沿用已验证回退。滚动条在滚动/悬停时可见，用户能发现后续内容。
- 文本与点击目标不随密度优化一并缩小：正文16px起，桌面主要控件至少32px，触屏目标44px。

先列页面清单再实施，不把资料库双栏机械套到所有模块。以下为待审计范围，不表示所有页面已发现同样问题：

| 页面类型 | 页面范围 | 统一规则 |
| --- | --- | --- |
| 目录/浏览 | 项目、角色、媒体、资料及搜索结果 | 标题/主操作、筛选、内容；取消重复标题与整行空工具栏；统一分页规则 |
| 阅读/编辑 | 资料详情、正文、大纲、角色详情、原作档案 | 主内容在首屏靠前，管理属性侧置；操作紧贴对象，保留阅读行宽 |
| 制作/生成 | 制作工作区、漫画、自由生成 | 围绕步骤/参数/结果分配空间；空结果不长期挤压输入区；状态说明合并 |
| 管理/概览 | 首页、日历、设置子页 | 尊重卡片概览、时间网格、配置表单各自任务；复用层级与间距，不强行双栏 |

每页记录：主要任务、唯一主动作、首屏主要内容、常驻工具、低频设置、滚动归属、空/长/失败状态、原截图、整改图、验收结论。

## 7. 实施次序与确认点

1. **建立基线与资料库原型**：同一笔记、同一皮肤、相同视口和侧栏状态，记录顶栏/正文起点/列表宽度；制作可点击原型，覆盖两条笔记、50条分页、长正文、属性展开、空结果。用户确认结构后才改生产组件。
2. **资料库完整落地**：先调整区域归属，再改结构和样式；同步独立笔记入口，防止出现两套编辑体验。接入真实数据，保持保存、返回、筛选、分页和离线能力。
3. **推广共享规则**：按上述页面类型逐组整改，复用模块顶栏、列表工具栏、文档工具栏、属性面板和分页，避免新增一批全局覆盖CSS。
4. **双重验收**：先检查视觉和任务效率，再跑功能回归。浏览器无报错不能作为视觉合格的代替。未通过样板页不进入批量推广。
5. **交付与部署**：提供页面覆盖表、同条件前后对照图、遗留问题和功能回归结果；确认后再部署。

## 8. 验收用例与通过标准

- 从资料库进入当前笔记，第一屏能够直接读正文，无需先越过多段管理表单；新建、搜索、加入项目的位置与作用对象一致。
- 普通编辑不强制打开属性；查看来源、修改标签、变更状态最多通过一个明确的属性入口到达。
- 2条与50条资料分别验收；搜索、清空筛选、跳页、改容量、前进后退、删除末页最后一条均正确，选中项可识别。
- 修改正文后切换笔记/模式、折叠列表、改变窗口大小不丢未保存内容；保存失败、离线、本机已存但尚未同步有明确区别。
- 标准桌面、超宽、窄桌面、390px窄屏及矮视口覆盖；暖夜为主要视觉验收皮肤，其余皮肤检查对比和几何一致性。
- 纯键盘能够访问块操作、属性、更多和分页；弹层关闭恢复焦点；不以hover作为唯一操作方式。
- 隔离数据验证写入与删除；正式环境只做读取检查。
- 以同状态截图和区域测量证明有效面积增加；同时标明哪些余白是阅读行宽需要，哪些已由结构调整消除。
