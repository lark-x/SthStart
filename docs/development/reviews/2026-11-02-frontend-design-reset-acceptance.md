# SthStart 前端设计重置验收报告

日期：2026-11-02
范围：除邻舍 `/apps/linshe` 与 `upstream/linshe` 外的内容页面
结论：**本轮基于真实数据副本的定向复验通过。** 页面信息架构、移动工作台、列表密度和交互可发现性均有可复现的改动；这不等同于对所有弹窗、异常态和完整业务流程的穷举验收。

## 1. 参考原则与本轮判断

DouUI 的参考原则包含两层：组件负责结构与行为，视觉由语义 Token 控制；界面通过字重、灰阶、分隔线和留白建立层级，只把强调色用于主操作和必要状态。页面之间的差异应来自任务结构，而不是重复叠加卡片、边框和常驻按钮。

上一轮仍有两个实现偏差：

- 页面外层从卡片网格变成列表后，内部仍然是卡片容器和密集操作，视觉上依旧像后台列表。
- 手机端公共工作台顶栏无条件把状态、导航和业务动作拆行，真实高度达到 117–141px，正文被压到首屏之外。

更早的验收主要使用 fixture 页面，未能暴露真实数据库中的长列表、失效媒体和移动工具栏问题。本轮改用隔离的真实数据库副本，并逐项查看真实截图与 DOM 尺寸。

## 2. 本轮实际修复

### 工作台与移动端

- 重写共享 `WorkspaceHeader` 的窄屏排列：标题、返回、导航、任务和业务动作保持单行；状态与中部视图切换不再产生无条件空白行。
- 剧情正式项目、剧情感想、活动工作室的移动顶栏实测均由 117–141px 收紧为 **52px**。
- 需要移动端操作的叙事与发布流程保留显式的 `centerSlotOnMobile` 选项，普通工作台不再为隐藏内容占位。
- 角色编辑的四个分段标签改为移动端短标签；306px 可用宽度内全部排下，不再出现截断。
- 手机端 PageTabs 保持单行横向滚动，避免设置页与生成配置页把标签折成多行。

### 列表与设置

- 活动列表移除包住 14 条记录的 16px 圆角大卡片，改为无外层卡片的连续分隔行；手机页高由 **2591px 降到 1467px**，单行实测 **83px**，并移除重复的“进入工作室”手机入口。
- 剧情项目列表与角色列表改为连续行，去掉外层卡片；活动菜单补充 `aria-haspopup`、展开状态、点击外关闭和 Escape 关闭。
- 新增可复用 `RowActionsMenu`：连接、文本模型和其他模型配置只常驻一个主操作，次要操作进入菜单；支持点击外关闭、Escape 关闭、焦点还原和方向键轮巡。
- 设置页服务连接移动页高由 1665px 降到 **1419px**。

### 真实媒体与状态

- 真实角色数据库中两个立绘 artifact 已处于 `missing`，但 profile 仍返回 URL，导致桌面和手机各出现 404 破图。
- 服务映射现在只向前端暴露文件状态为 `ready` 且本地文件存在的角色资产；资产列表同步过滤失效记录，保留数据库元数据供后续重新关联或清理。
- 复验中角色主图正常显示，角色详情页网络失败为 0。
