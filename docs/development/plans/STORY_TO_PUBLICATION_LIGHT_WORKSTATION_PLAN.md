# 从剧情到发布：轻量创作链实施规格

日期：2026-10-03。用户已授权实现；本轮不提交、不部署、不向异常真实库迁移或写测试数据。

## 目标与边界

正式剧情 → 冻结章节版本 → Harness 提交制作方案 → 人工确认方案、配置和预算 → 关键帧、逐句配音 → 图片漫画与静态配音视频 → 审阅并手动发布。

保留剧情＋简化制作台。旧活动和旧漫画继续可读，制作选图不改 `SceneBeat.mediaUrl`，不反写剧情。旧 Story 桥接六工具不扩大权限，新制作 MCP 使用独立项目凭据，仅管理员能批准费用。Token 只保存哈希，密钥从独立语音配置的环境或系统凭据库读取，不复制 DSH 模型密钥。

首版：6–12 关键帧，建议 1–3 分钟、最多 5 分钟；竖屏优先，可选横屏。图片默认 768×1024，单张生成、串行 ComfyUI，不自动 Hires。每次批准图片额度最多关键帧数＋3（绝对上限 15）。未知提交结果也占额度，禁止自动重投。无语音配置仍能做漫画，视频必须配音齐全。

Harness 编写结构化英文生图提示词；服务端校验角色与来源，只追加固定风格、负向词及 LoRA 触发词，不再次调用提示词优化模型。全局→角色→画格的 LoRA 合并复用现有能力，多角色同名冲突拦截。批准冻结工作流、预设、参数、LoRA、语音模型和预算；配置改变需重新批准。

## 阶段与职责

0. 保存工作区基线、契约与 Story 靶向测试。真实数据库有已知损坏，使用内存/临时文件库开发，不执行真实迁移。保护已有大量改动与邻舍子模块指针。
1. `activity-publication.ts` TypeBox 契约、迁移 50、独立草稿 CAS/不可变版本/审批/任务/凭据/语音配置。章节来源使用真实 `story_entry_revisions`，不伪造旧版本。图片、音频、导出都建立产物引用。
2. 剧情增加“制作作品”，先 flush，再冻结选定章节。制作台三页：制作方案／画面与配音／预览与导出。正文、对白和画面常驻，模型、LoRA、配音和高级参数放响应式弹窗。独立滚动，窄屏 Drawer，旧活动继续走旧工作台。
3. 单独制作 MCP 八工具：get_source_bundle、get_publication、propose_publication_plan、start_approved_run、get_run_status、stop_run、retry_shot、select_shot_image。项目范围凭据和精确 Portal 代理。不提供 approve 工具。运行先落库，幂等预算，重启核对统一生成任务，不凭模型上下文恢复。生图只走 `createGenerationTask`。
4. 独立 OpenAI-compatible `/audio/speech` 配置：URL、模型、voice 清单、默认 voice、速度、密钥引用。按句生成并可 WAV/MP3/M4A 替换，保存实际时长。改对白只使该句音频失效，改图像描述只使该图失效；旧历史仍在。
5. 共用纯时间线、Canvas 漫画布局。每页图像与正文分开渲染，最多三句一张卡、多句拆卡复用图片。竖图 1080×1440、横图 1920×1080；视频 1080×1920／1920×1080、30fps、H264/AAC、FFmpeg CPU threads=2。实际音频时长＋句间250ms＋镜末400ms，无对白3秒。只静止/轻推1→1.03、硬切；字幕按句/长度比例分段，不宣称字级对齐。字体使用本地 Noto Sans SC，缺图/音频/字体/FFmpeg 禁止成功导出。
6. 临时项目真实小样：60–90秒、六关键帧、最多两张重绘，人工检查后下载漫画、视频与发布 ZIP。真实数据库/凭据未就绪则明确未验证，不虚报完成。

## 导出与安全

不可变制作版本导出 `video.mp4`（可选）、`cover.png`、`images/page-001.png`、`subtitles.srt`、`publish-copy.md`、`manifest.json`。封面复用已有图加文字，不额外花生图额度。ZIP 不含密钥、完整生成提示词或日志。FFmpeg 使用参数数组、无 shell、无模型指定命令/路径/URL。

不做平台自动上传、BGM、口型、连续动画、图生视频、语音克隆、LoRA 训练、本地 TTS；在线配音密钥及实际服务由用户配置。

## 靶向验收

只测试本轮：章节冻结/CAS/不可变版本、旧活动不变；MCP 范围/撤销/不能批准；运行幂等/预算/未知/重启不重投；无二次提示词优化；对白音频局部失效；真实时长/字幕；文字溢出/缺图拒绝；10秒 MP4 编码检查；漫画和发布 ZIP 内容。运行契约测试、相关服务测试与类型检查、涉及的构建。桌面1440×900与窄屏390×844检查制作台和剧情入口，不进行全站重测。
