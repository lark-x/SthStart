# 故事世界配置与 AI 填充

## 使用流程

1. 从“作品 → 新建作品”，或从创作项目的创建入口打开创建页。作品列表同时包含角色库登记的作品、尚未配置故事的作品与已有故事；无角色也会显示，支持名称与别名搜索。
2. 填写作品名称、选择原作/同人/原创（默认原创），同人再选母原作，即可创建并返回列表。刷新后仍然保留，无需先填模型、人物或地点。需要开展故事时点击“配置故事”，添加一个开场地点和至少一名主要人物；人物可从角色库的已保存阶段导入，也可新建原创人物。地点和人物未齐时可以保存部分设定。目录中已有作品配置故事时沿用其名称和属性，避免重复登记。
3. 需要联网时，在“公共服务 → 其他服务”配置并启用 Tavily。密钥安全保存，不会返回到浏览器；也可通过 `STHSTART_TAVILY_API_KEY` 环境变量配置。
4. 从参考资料选择器的“网页”页搜索，勾选网页后提取正文，核对正文或摘要、失败与截断提示，再确认加入草稿。默认标记待核实；“保存至资料库”另行操作。
5. “补全设定”页通过顶栏“AI 候选”打开辅助抽屉，关闭再打开保留输入。填写创作要求并选择范围；候选有当前值、建议值、引用和缺口，默认不勾选。选择后明确采纳才修改草稿；依赖地点必须一并选择，已改变的字段或来源需要重新核对。
6. 地点和人物齐备后点击“完成配置”，原子建立世界主定义与初始主线，世界 ID 保持不变。待配置世界不能运行或绑定项目；完成后也不会自动推演，仍需显式启动运行。
7. 旧版本尚未创建的本机草稿通过新建页“继续旧草稿”恢复，沿用原完整配置和组合创建流程。

## 编辑与失败恢复

- 世界设定影响公共模板，故事方向影响当前分支；两个作用范围在页面分别说明，可单独保存。
- 本机草稿保存在当前浏览器会话，刷新、返回、打开资源选择器不会清空。浏览器清理会话存储后不保证恢复，草稿不是云端备份。
- 同时编辑产生修订冲突时，不自动用最新修订覆盖。先读取服务器当前值，与草稿逐字段比较，再确认基准后保存。
- 世界与分支部分保存失败时，已保存的一侧如实提示，未保存内容保留。活动运行期间不能直接修改分支方向，可先保存世界设定或新建分支。
- 会话失效仅对明确的 `invalid_csrf` 刷新并最多重试一次；不会关闭安全校验，也不会把所有 403 当作会话失效。
- 重复创建与响应丢失后的同内容重试沿用持久幂等标识。AI 调用超时不会自动再次付费生成，已有候选和草稿保留。
- 候选 ID 与人物、地点的实体 ID 含义不同。模型复用了已有实体 ID 且没有其他候选引用它时，服务会分配独立候选 ID；如果依赖引用存在歧义，整批拒绝并保留草稿，要求人工重试。不会重写实体 ID 或猜测依赖。

## 侧栏与外观

- 桌面侧栏的收起状态在切换页面、刷新和同源标签页之间保持一致；首屏读取已保存偏好，避免加载后再展开。
- 导航滚动条平时隐藏，滚动时显示，停止约 800ms 后隐藏。高对比度系统保留原生滚动条。
- 侧栏外观按钮直接切换日间和夜间。详细主题、皮肤和自定义主题色位于“系统设置 → 外观”；每项有“预览”，样例界面不会更改全局外观，点击“应用”后才保存。

## 模块衔接

- 角色库、已保留资料、笔记、叙事档案、项目和网页共用资源选择器。已发布角色版本与来源快照保留；新版本必须人工比较确认，不按姓名冒认身份。
- 从项目建立世界不会自动覆盖项目绑定。替换既有绑定需要确认；另一个窗口抢先改绑时返回冲突。
- 正文采纳独立选择整条分支中的事件范围，不受画布筛选限制。人物视角必须在所有所选事件中有效。预览后采纳为新章节，可继续编辑或带入制作。
- 标题最多 120 字符，正文最多 100000 字符；超出正文上限需缩小事件范围，不静默截断。
- 世界配图预览保留事件来源，“加入项目”引用现有媒体，不复制图片文件。
- 从其他模块选入并实际发送的参考图使用既有媒体引用权限，新建授权最长 24 小时，不延长既存有效授权；同一时间提交通过临时引用租约保护，启动恢复会清理上次进程遗留租约并收敛未完成的提交记录。当前恢复按本地单服务实例部署设计。

## 验证入口

- `npm run test:contracts`
- `npm run typecheck`
- `npm run check:architecture`
- `npm run test:regression`
- `npm run build`
- `npx playwright test --config tests/config/playwright.world-authoring.config.ts`
- `npx playwright test --config tests/config/playwright.story-worlds.config.ts`

两套浏览器验证使用临时数据库与受控外部服务，不向真实业务库写测试世界。隔离验证不等于 Tavily 真实联网与真实模型内容验收；后者分别要求有效密钥与可用文本模型。正式部署记录与实际验收结果另记于 `docs/development/reviews/`。
