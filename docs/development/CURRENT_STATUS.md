## 当前开发重点

1. 先收敛 Generation 模块边界，避免继续向单个执行文件堆叠功能。
2. 完成 Worker/H3 工作流的管理闭环和严格就绪检查。
3. 补齐 Worker 系统资源、GPU、模型、节点和 Generation Queue 诊断。
4. 真实 H3、跨平台、大文件和完整浏览器验收统一保留到稳定化阶段执行。
