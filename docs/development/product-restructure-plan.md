# SthStart 模块重组实施计划

目标：以创作项目串联资料、角色、正文、制作和媒体；独立随记、原文检索、自由生成继续可用。保留旧路由与现有数据，不改邻舍内部。全程不使用Terra。

## 交付阶段与完成条件

1. 信息架构：新增创作项目/资料库/媒体库入口；主导航按创作、资源、工具与系统分组；旧剧情、活动、笔记等入口仍能从新导航与命令面板到达。首页最近工作包含剧情项目，术语区分来源作品/创作项目/制作版本/导出成品。
2. 项目关系：项目概览汇集正文、角色、采用资料与制作。资料采用冻结来源摘要；资源更新/失效可见，不能静默覆盖。角色从主库选择已发布版本，保留来源；快速制作不再只复制姓名。章节制作统一走已有冻结修订的正式链路，移除伪“一键编译”行为。既有独立制作可关联项目，不自动归类或搬移。
3. 资源与工具：全局媒体视图显示各业务产物、可用状态和来源，提供项目采用与返回原业务；灵感/笔记/原文/搜集任务入口归入资料库，个人感想保留数据并从资料页访问。自由生成与项目内生成分工明确。设置按用途说明连接、方案和运行诊断边界。
4. 验收：临时数据库验证迁移保留、引用与版本、错误输入、权限和跨模块路径；浏览器检查项目→资料/角色→章节→制作，以及资源原位置回溯；桌面1440/1920，代表性1024/390回归。真实库先备份再升级，禁止为测试调用付费生成。

## 实施约束

- 复用story项目和现有内容版本，不创建第二套正文或角色主档案。新增关联表是对现有对象的连接，不迁移或删除原内容。
- 项目资料的“加入参考”和“采用为设定”有不同结果；前者保留快照，后者在明确操作后创建独立正式文档并保留来源。
- 图像、视频、音频继续使用中央artifact存储；全局浏览不撤销跨应用授权。缺失文件显示缺失，不伪造恢复。
- DSH保留真实独立配置与凭据边界，基础编辑不依赖DSH连接。
- 本轮在已验收的独立工作树实施，最终合回主工作区时保留原有未提交后端和邻舍改动。
