## 工具适配（实测结论）

- 主力 `search`（type=dialogue/structured/document/quest；**单关键词查询最稳**，多词并查易落空；`speaker=` 过滤部分会话可用）
- `get_character` / `resolve_entity` 部分会话可调用（拿星级/武器/canonical 名的硬证据）；`get_entity_texts`/`get_relationships` 返回空绑定（弃用）
- `get_quest(quest_id, node_limit)` 可用但**整篇拉取曾导致代理上下文超载失败**——定点小页或 dialogue 检索替代
